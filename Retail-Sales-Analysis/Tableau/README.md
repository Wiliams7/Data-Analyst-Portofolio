
# Tableau - Retail Sales Dashboard

## Project Overview
This project focuses on building an interactive retail sales dashboard using Tableau to monitor business performance and visualize key sales metrics.

The dashboard uses the Sample Superstore dataset and presents insights through interactive charts and filters.

## Tools & Technologies
- Tableau
- Sample Superstore Dataset

## Dashboard Overview

The dashboard provides an overview of retail business performance through the following visualizations:

- Sales by Category
- Profit by Region
- Sales by Segment
- Sales Trend by Year
- Top 10 Products
- Profit by Sub-Category

## Key Performance Indicators (KPIs)
The dashboard includes key metrics to monitor business performance:

- Total Sales
- Total Profit
- Total Orders
- Profit Margin

## Interactive Features
- Region Filter
- Year Filter

These filters allow users to explore sales performance across different regions and time periods.

## Key Objectives
- Monitor overall sales and profitability.
- Compare performance across product categories.
- Identify regional sales and profit performance.
- Analyze yearly sales trends.
- Identify top-performing products.
- Support data-driven business decisions.

## Conclusion
This project demonstrates the use of Tableau to create an interactive dashboard that transforms retail transaction data into meaningful business insights.
