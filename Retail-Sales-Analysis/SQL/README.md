
# SQL - Retail Sales Analysis

## Project Overview
This project focuses on analyzing retail sales data using SQL to identify business performance, sales trends, and profitability insights.

The analysis uses the Sample Superstore dataset and PostgreSQL to explore the data and answer relevant business questions.

## Tools & Technologies
- PostgreSQL
- DBeaver
- SQL

## Dataset
The project uses the Sample Superstore dataset, which contains retail transaction data, including:
- Order Date and Ship Date
- Customer and Order Information
- Product Category and Sub-Category
- Sales, Quantity, Discount, and Profit
- Region and Segment

## Analysis Process

### 1. Data Preparation
File: `01_Data_Preparation.sql`

Activities:
- Data overview and exploration
- Data validation
- Table creation
- Data structure and consistency checks

### 2. SQL Analysis
File: `02_SQL_Analysis.sql`

Activities:
- Sales and profit analysis
- Performance analysis by category and sub-category
- Regional and customer segment analysis
- Shipping mode analysis
- Product performance analysis
- Time-based sales analysis
- JOIN operations for combining related data

### 3. Advanced SQL
File: `03_Advanced_SQL.sql`

Activities:
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- CASE WHEN statements

## Key Objectives
- Understand overall retail sales performance.
- Identify profitable and underperforming product categories.
- Analyze sales performance across regions and customer segments.
- Evaluate customer and product performance.
- Explore sales trends over time.
- Apply SQL techniques to support data-driven business insights.

## Conclusion
This project demonstrates the use of SQL for data preparation, exploratory analysis, business analysis, and advanced querying using PostgreSQL.
