
# Python - Retail Sales Analysis

## Project Overview
This project focuses on analyzing retail sales data using Python to explore business performance, identify trends, and generate actionable insights.

The analysis uses the Sample Superstore dataset with Pandas, NumPy, Matplotlib, and Seaborn.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Visual Studio Code

## Dataset
The Sample Superstore dataset contains retail transaction information, including:
- Order and shipping dates
- Customer information
- Product categories and sub-categories
- Sales, profit, quantity, and discount
- Region and customer segment

## Analysis Process

### 1. Data Loading & Exploration
- Importing the dataset
- Understanding dataset structure
- Checking data types and dimensions
- Exploring statistical summaries

### 2. Data Quality Assessment
- Checking missing values
- Checking duplicate records
- Validating data types
- Inspecting date columns

### 3. Exploratory Data Analysis (EDA)
- Sales and profit performance
- Analysis by category and sub-category
- Regional performance
- Customer segment analysis
- Shipping mode analysis
- Customer and product performance
- Yearly sales trends

### 4. Data Visualization
Creating visualizations to identify patterns and communicate business findings.

## Key Objectives
- Understand retail sales performance.
- Identify profitable and underperforming categories.
- Analyze customer and regional performance.
- Discover sales trends and patterns.
- Generate business insights from data.

## Conclusion
This project demonstrates the use of Python for data exploration, quality assessment, exploratory data analysis, visualization, and business insight generation.
