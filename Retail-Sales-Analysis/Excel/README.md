# Retail Sales Analysis - Excel

## 1. Project Overview
This project analyzes retail sales data using Microsoft Excel
to identify sales performance, profitability, and business trends.

## 2. Dataset Source
Dataset: Sample Superstore

Source: [Kaggle - Sample Superstore Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)

Dataset contains 9,994 records and 21 columns.

## 3. Tools Used
- Microsoft Excel

## 4. Data Cleaning
- Checked missing values.
- Checked duplicate records.
- Validated data types.
- Checked numerical values.
- Validated order and shipping dates.

## 5. Data Analysis
- PivotTable analysis.
- SUMIFS and COUNTIFS.
- IF function.
- XLOOKUP.
- Sales and profit analysis.

## 6. Dashboard
Dashboard includes:
- Total Sales
- Total Profit
- Total Quantity
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Interactive Slicers
